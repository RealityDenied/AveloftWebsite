Product 02 · Unity Editor · World building

Mesh Terrain Editor

A custom Unity tool for sculpting chunked mesh terrain instead of fighting the built-in terrain stack. Height brushes, live collider refresh, NavMesh-aware rebuilds, and per-chunk materials — the same pipeline we use on our own maps.

  • Chunked mesh terrain (example: 4×4 chunks, 256×256 m, 129×129 verts)
  • Raise / lower brushes with radius, strength, and falloff
  • Rebuild all chunks, refresh colliders, apply materials and masks
  • Hooks for procedural generation and AI Navigation surfaces
